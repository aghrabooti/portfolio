# aghrabooti portfolio

A Next.js portfolio for selected web apps, Telegram bots, and Persian text tools.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

Edit the project descriptions and technology lists in `data/portfolio.ts`. The homepage and project panels live in `app/page.tsx`. The Three.js hero scene lives in `components/HeroAtlas.tsx`.

Design reference: [Hamish Williams](https://hamishw.com/).
